## 💻 Linguagens de Programação e Compiladores (C05) - Inatel

### 📌 Sobre o Repositório

Este repositório contém todos os códigos, listas de exercícios, seminários, trabalhos e materiais desenvolvidos durante a disciplina **C05 - Linguagens de Programação e Compiladores**, cursada no **Instituto Nacional de Telecomunicações (Inatel)**.

O objetivo da disciplina é introduzir os conceitos fundamentais das linguagens de programação e dos compiladores, abordando análise léxica, sintática e semântica, além do estudo de paradigmas de programação e do processo de compilação.

* **Semestre:** 2026/1
* **Professor:** Daniel Mosca
* **Aluna:** Caroline Ferreira de Souza

### 🚀 Tecnologias Utilizadas

* **Linguagens:** Python, Erlang e outras linguagens estudadas na disciplina
* **Ambiente de Desenvolvimento:** VS Code

### 💡 Como Executar

Para compilar e rodar os códigos deste repositório:

1. Clone o repositório:
   `git clone https://github.com/carolferreirauai/c05_lps_e_compiladores.git`

2. Navegue até a pasta do arquivo desejado via terminal.

3. Compile o código conforme a linguagem utilizada.

4. Execute o programa utilizando o compilador ou interpretador correspondente.
